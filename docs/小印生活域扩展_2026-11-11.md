# 小印生活域扩展（2026-11-11）

把小印（preset「小印·私人助理」，id 仍是 `private-print-assistant`）从「打印助手」扩成「打印主业 + 生活杂事」。
两个验收动作：

- 「帮我打开一下网易云音乐」→ 启动/唤起网易云音乐；
- 「帮我将微信聊天框转到某某的对话框」→ 复用发消息那套键盘链路，把微信切到该会话，**只切不发**。

## 为什么这么改

1. `app_launch` 原来只认 `print_tool` / `wcda` 两个白名单，人设也明令「只这两个」——这是生活域最直接的卡点。
2. 打开微信会话不需要新链路：`kbd_send.send_text` 的前半段（Ctrl+Alt+W → Ctrl+F → 全名 → Enter → 左侧面板差分确认）
   已经稳定跑过很多单，缺的只是「打开后不发送」的出口。
3. WCDA 是独立分析客户端，不控制微信 UI，没有「打开会话」的 API；切会话只能走键盘链路（设计稿 2026-11-04 已确认）。

## 行为约定

- `app_launch(app="网易云音乐")`：只认开始菜单名字 / config 里的 label，**不收路径、不收参数**；找不到回 `unknown_app` + `candidates`，
  人设要求先 `app_list` 或问人，不猜。已经在跑时回 `code:"activated"`（再唤一次），没跑回 `"started"`。
- `print_tool` / `wcda` 即使开始菜单里也能解析到，仍转回固定入口（旧版安装目录的 `HN打印工具.exe` 控制口对不上）。
- `app_list(q=...)`：只读，最多 40 条，用来消歧。
- `wechat_open_chat(to=全名)`：键盘链路只做「唤起微信 → Ctrl+F → 清空 → 打全名 → Enter → 左侧面板差分」，
  不碰剪贴板、不发消息；`state:"opened"` 才算切好，`failed` 带 `shots`。目标名字要先由 `wechat_contacts` / 别名表定准。
- 群聊也可以切（只切不看、不发）；发消息的群聊限制不受影响。

## 上线

1. 桥改动**不需要重装**，但 MCP 进程是长驻的：**完全退出并重启 DSH 桌面端**（或新开小印会话）才会加载新的 `mcp_server.py`。
2. 人设改动同样只对新会话生效（persona 在 preset 组装时注入）。老会话继续用旧人设，不会热更新。
3. 改 system prompt 会作废前缀缓存，别去恢复几十万 token 的老会话；直接开新会话。

## 已知限制

- 微信搜索回车会打开**第一个**候选：名字不唯一时工具无法替你选，所以人设强制先 `wechat_contacts` 定人、拿不准先问。
- 开始菜单里没有的程序（绿色版、UWP 无快捷方式）解析不到；需要时往 `config.local.json` 的 `life_apps` 里补。
- 生活程序启动后只等 2.5 秒确认进程起来，不等窗口就绪；唤醒失败时 hint 会请人点任务栏。
- 只启动、不关闭：关程序仍由人来做（关打印工具会打断正在出的纸）。
